# I Regni di Tuzu

Un villaggio da far crescere fra i popoli Tuzu: di giorno costruisci, di notte difendi, e nel mondo online
incontri i villaggi degli altri giocatori.

**Gioca:** https://game.tuzu.my

Questa cartella è solo la copia pubblicata. Il progetto vero (codice, prove, appunti) sta in `TuzuDifesa`:
qui arrivano `index.html`, `src/` e `vendor/` copiati da `www/`.

Il gioco precedente («L'Èrebo») è stato tolto il 19/11/2026 su richiesta del titolare. Si ritrova intero
all'etichetta git `vecchio-gioco-erebo`. I suoi dati nel database (`game_saves`, `game_wallet`,
`game_leaderboard`) non sono stati toccati.
